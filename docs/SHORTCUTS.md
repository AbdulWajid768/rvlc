# Keyboard shortcuts

Player shortcuts are configurable in **Settings › Shortcuts** and listed in the
app under **Help › Keyboard Shortcuts** (⇧/ or F1). They are inactive while you
type in a text field, and list views keep their navigation keys; ⌘ shortcuts
keep working everywhere.

## Playback

| Action | Default |
|---|---|
| Play / Pause | Space (also click the video once) |
| Stop | ⌘. |
| Previous / Next item | P / N (or Page Up / Page Down) |
| Seek back / forward (step, 5 s by default) | ← / → |
| Seek back / forward 1 s | ⇧← / ⇧→ |
| Seek back / forward 30 s | ⌥← / ⌥→ |
| Previous / next frame | , / . |
| Volume down / up | ↓ / ↑ |
| Mute | M |
| Slower / faster / normal speed | [ / ] / ⌫ |
| Toggle full screen (instant, no animation) | F (also double-click the video, or ⌃⌘F) |
| Exit full screen | Esc |

## Subtitle sync

| Action | Default |
|---|---|
| Subtitles earlier / later (by the step, 100 ms default) | Z / X |
| Reset subtitle timing | ⇧Z |
| Sync selected line to now | Y |
| Show / hide subtitles | S |
| Next subtitle track (including Off) | J |

## Audio sync

| Action | Default |
|---|---|
| Audio earlier / later (by the step) | C / V |
| Reset audio delay | ⇧C |
| Next audio track | A |

| Playlist / Library / Subtitle Studio / Audio Sync Lab / Picture & Sound | ⌘1 … ⌘5 |
| Toggle Sidebar | ⌃⌘S |
| File Info | ⌘I |
