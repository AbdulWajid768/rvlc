The signature feature

Smart Subtitle Sync

Every way subtitles go wrong, handled in one sidebar. Nothing is applied until you say so: every suggestion can be previewed, applied or discarded.

1

Live offset

Shift subtitles by ±100, 250 or 500 ms, or type an exact millisecond value. Changes show instantly while the video plays.

Z earlier X later ⇧Z reset

2

Sync to speech

Pause on a spoken line, pick it, and sync it to now. One point fixes an offset; two or more across the film also fix drift, like 23.976 ↔ 25 fps, with a fit-quality readout.

Y sync selected line

3

Automatic sync from audio

RVLC compares speech in the soundtrack with subtitle timing and suggests an offset and frame-rate drift, with a confidence level. It all runs on your Mac.

4

Export, never overwrite

Save a corrected SRT, WebVTT or ASS file (ASS styling preserved). The original subtitle file is never modified.

Everything else

A complete player, built natively for the Mac

Playback runs on libmpv with FFmpeg underneath, so RVLC plays the same wide range of formats as mpv. The interface is native AppKit, written in Swift.

Subtitle Studio

Import SRT, WebVTT and ASS/SSA with automatic encoding detection (UTF-8/16, Windows code pages, Shift JIS, GB18030, Big5…) and a manual override. Invalid files get a clear message.

Subtitle editor

Edit text and timings, search & replace with case, whole-word and regex options, nudge lines, set start to now, undo/redo, all with live preview. ⌘E

Audio Sync Lab

An independent audio delay, remembered per file. Add external audio tracks such as a dub and switch tracks. C / V to nudge.

Player

Precise seeking down to a single frame, a scrubbable timeline whose hover bubble shows exactly where a click lands, Go to Time (⌘J), speed 0.25–4×, instant full screen and drag & drop.

Library & playlist

Recently played with resume positions, favourites, search and sorting, file info. A persistent, reorderable play queue with repeat modes, and whole folders at once.

Picture & Sound

Aspect override, fit/fill/stretch, brightness, contrast, saturation, gamma, rotation, hardware decoding, equalizer presets, loudness normalisation and amplification to 200 % with a limiter.

Native macOS design

Light, dark and system themes, a responsive layout, VoiceOver labels and configurable keyboard shortcuts that never get in the way of typing.

Private by design

No account, no telemetry, no analytics and no network requests. Your media, subtitles and audio analysis never leave your Mac.

Install

Up and running in a minute

  1. Download the DMG

    Use the Download for macOS button. The download is the latest release from GitHub.

  2. Drag RVLC to Applications

    Open the downloaded DMG and drag RVLC onto the Applications shortcut.

  3. Allow it on first launch

    RVLC is not yet notarised by Apple, so macOS blocks the first launch. Open RVLC once, click Done, then go to System Settings › Privacy & Security, scroll down and click Open Anyway. You only need to do this once.

    Prefer the Terminal?

    This removes the quarantine flag macOS adds to downloaded apps:

    xattr -dr com.apple.quarantine /Applications/RVLC.app

RVLC needs a Mac with Apple silicon running macOS 26 or later. It is free software under the GPL; you can also build it from source.
