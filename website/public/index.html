  1. 01

    Nudge

    Shift by ±100, 250 or 500 ms, or type the exact millisecond. You see the change on screen while it plays. Z X ⇧Z

  2. 02

    Point & sync

    Pause on a spoken line and sync it to now. Add a second point late in the film and RVLC also fixes drift, like 23.976 ↔ 25 fps, with a fit-quality readout. Y

  3. 03

    Listen

    RVLC compares speech in the soundtrack with subtitle timing and suggests an offset and drift, with a confidence level. Preview it, apply it, or discard it.

  4. 04

    Export

    Save a corrected SRT, WebVTT or ASS file, with ASS styling kept. Your original subtitle file is never touched.

Ch. 04 Install

Three steps. One minute.

  1. 00:00

    Download

    Get the DMG with the download button. It comes straight from the latest GitHub release.

  2. 00:15

    Drag to Applications

    Open the DMG and drop RVLC onto the Applications folder.

  3. 00:30

    Allow the first launch

    RVLC isn't notarised by Apple yet, so macOS asks once. Open RVLC, click Done, then choose System Settings › Privacy & Security › Open Anyway.

Or in Terminal
$ xattr -dr com.apple.quarantine /Applications/RVLC.app

Needs a Mac with Apple silicon running macOS 26 or later. Free software under the GPL. You can also build it from source.
